CARTÕES PT — Flashcards em português de Portugal

1. Abra index.html no navegador do computador ou telemóvel.
2. Para usar no telemóvel, pode publicar esta pasta num serviço de alojamento web e adicionar o site ao ecrã inicial.
3. Os dados são guardados localmente no navegador.
4. Use Dados > Exportar dados para fazer cópias de segurança.

A aplicação inclui:
- Baralhos personalizados
- Cartões frente/verso
- Virar cartão
- Baralhar
- Marcar "Já sei" / "Rever"
- Pesquisa
- Exportação/importação JSON
- Interface em português de Portugal
